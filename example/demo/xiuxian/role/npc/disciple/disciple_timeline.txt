# 外门弟子对话时间线（GdDialogue 语法，本角色专属）
# 语法：[stage@标记] 舞台；(角色名) 说话人轮换；- 选项@动作；
#       @函数:参数 调用对话 control 上的方法；:goto:stage 控制流
#
# 入口优先级：听闻失窃（theft_rumor）→ 令牌伏笔段（beat 6，置 token_clue）；
# 日常指路兜底。段尾无 goto = 对话自然结束（本文件惯例）。

[disciple_theft@theft_rumor;!token_clue]
(外门弟子,云舟)
师兄听说了吗？昨晚执事堂遭贼！我夜里起来透风，瞧见一条黑影翻墙走了。
那黑影袖口露出半块令牌——玄铁的，刻着云纹，可不像咱宗门的东西。
(云舟)
云纹令牌……你看真切？
(外门弟子)
千真万确！哎，你可别说是我讲的。执事长老这几日脸色差得很，
你去执事堂瞧瞧吧，八成正为这事犯愁呢。
- （云纹……先去找执事长老）@set_flag:token_clue;goto:disciple_gate

[disciple_talk]
(外门弟子,云舟)
师兄也是新来的吧？这座坊市我最熟！
- 传送阵都在哪里？@goto:disciple_gate
- 你怎么不去历练？@goto:disciple_lazy

[disciple_gate]
(外门弟子)
东门出去是青草岭，北边小径通幽竹林。
地图上发亮框的地方就是传送阵，站上去就能走。

[disciple_lazy]
(外门弟子)
咳，我这是……战略性地保存实力！等你从青草岭回来再聊。
