# 执事长老对话时间线（GdDialogue 语法，本角色专属）
# 语法：[stage@标记] 舞台；(角色名) 说话人轮换；- 选项@动作；
#       @函数:参数 调用对话 control 上的方法；:goto:stage 控制流
#
# 入口 stage 按排列顺序做优先级（get_first_flag 从头扫描取第一个满足者）：
#   1. elder_main4_final  突破斗者后复命收束（main_004 完成位）
#   2. elder_main4        见令牌吐真相 + 赠聚气散×3 + 接 main_004（beat 7 前半）
#   3. elder_exam         考校 + 报到（main_001 的接取与 talk 步推进位，beat 4）
#   4. elder_talk         日常兜底
#
# 红线：段内行函数（@set_flag/@task_accept 等）会改变状态，若该状态参与
#   本段 gate 表达式，则从变更行推进到后续行时 gate 失配 → 对话直接断线
#   （timeline.next() 先查 gate 再取行）。因此**所有变更本段 gate 状态的
#   操作必须写在选项动作里**（exec_response 内变更+goto 连续执行，中间
#   不经过 stage 检查）；行上只放不影响本段 gate 的变更。
# 链式选项动作语法：首命令带 @，后续命令裸写（@a:1;b:2;goto:xx）。
# rank_dou_zhe 标记由 try_breakthrough 进入斗者阶时置位（M4 联动）。

昨夜失窃的是十年前的坊市底册，上面记着你父亲入职的印押与监印人名讳。
