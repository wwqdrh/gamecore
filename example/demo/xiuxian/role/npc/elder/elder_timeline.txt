# 执事长老对话时间线（GdDialogue 语法，本角色专属）
# 语法：[stage@标记] 舞台；(角色名) 说话人轮换；- 选项@动作；
#       @函数:参数 调用对话 control 上的方法；:goto:stage 控制流
#
# 所属篇章：宗门篇（第二阶段）——玩家通过宗门选拔录入青云宗后的对话位。
# 家族篇的真相段（main_004 赠药/复命）已迁往萧老爷（master_timeline）。
#
# 入口 stage 按排列顺序做优先级（get_first_flag 从头扫描取第一个满足者）：
#   1. elder_report   宗门报到（main_201 的 talk 步推进位）
#   2. elder_daily    每日签到（daily_201 接取与推进）
#   3. elder_talk     日常兜底
#
# 红线：段内行函数（@set_flag/@task_accept 等）会改变状态，若该状态参与
#   本段 gate 表达式，则从变更行推进到后续行时 gate 失配 → 对话直接断线。
#   因此**所有变更本段 gate 状态的操作必须写在选项动作里**（exec_response
#   内变更+goto 连续执行）；行上只放不影响本段 gate 的变更。

# ---- stage2 main_201 报到：talk 步推进位 ----
# goto 步（山门/弟子舍）由测试或后续换图钩子推进；本段推进 talk 步
[elder_report@task_main_201_accepted;!task_main_201_step2]
(执事长老,云舟)
选拔前十——不错，青云宗收你了。
名册在此登记，外门弟子舍在西院，安顿去吧。
往后每日来执事堂签到，别懈怠。
- 弟子告退。@task_advance:main_201;goto:elder_end

# ---- stage2 daily_201 每日签到 ----
[elder_daily@!task_daily_201_done]
(执事长老)
签到？册子在案上，按个手印，领今日的供奉。
- 签到。@task_accept:daily_201;task_advance:daily_201;goto:elder_end

# ---- 日常兜底 ----
[elder_talk]
(执事长老,云舟)
有事？说吧。
@set_flag:met_elder
- 请长老指点修行门路。@goto:elder_guide
- 坊市里有什么值得逛的？@goto:elder_market

[elder_guide]
(执事长老)
修行如逆水行舟，先把体魄与根骨打牢，再谈境界突破。
东边青草岭多妖兽灵草，正合练手；北面幽竹林阴气重，没本事别去。
(云舟)
弟子记下了。
:goto:elder_end

[elder_market]
(执事长老)
坊市在南边，丹药法器一应俱全。只是灵石有限，要花在刀刃上。
:goto:elder_end

[elder_end]
(执事长老)
去吧。若在山外遇了麻烦，记得回来找执事堂。
