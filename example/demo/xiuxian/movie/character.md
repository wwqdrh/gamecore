# 《青云问道》人物设定（宗门篇）

> 第二阶段（宗门篇）剧情演出人物志。现有角色沿用 stage1 设定，本篇新增
> 5 位宗门线角色（对应 `role/npc/` 下新建目录）。主角身世暗线（玉佩 /
> 药王谷 / 魔道追杀）自本篇铺开，作为第三阶段的引线。

---

## 一、主角与家族（现有角色）

### 萧炎（player，玩家角色）
- **身份**：萧家独子，宗门选拔夺魁后录入青云宗外门。
- **性格**：外温和内坚韧，穿越者视角的清醒与「前主身世」的朦胧记忆并存。
- **成长弧**：家族篇的「站稳脚跟」→ 宗门篇的「立足与抉择」——在宗门
  等级秩序与同门倾轧中守住本心，第一次直面「身世」二字。
- **关键信物**：**旧玉佩**（c01 父亲赠出）——温润青玉，纹路似篆非篆，
  靠近残碑/魔修时会发热共鸣。身世线的核心道具。

### 萧战（xiao_master，萧老爷）
- **身份**：萧家家主，斗者巅峰，家族篇真相段曾吐露「旧事」。
- **本篇**：c01 辞行戏。送子出乡，交玉佩时欲言又止——他知道些什么，
  但「等你筑基再说」。

### 柳氏（xiao_lady，萧夫人）
- **本篇**：c01 辞行戏。慈母线，缝衣塞物，不问修行问冷暖。

### 小翠（xiao_maid，丫鬟）
- **本篇**：c01 辞行戏。塞干粮、抹眼泪，家宅线的牵挂收束。

## 二、宗门线·新增角色（本篇新建）

### 凌霄真人（sect_master，青云宗宗主）
- **身份**：青云宗宗主，筑基后期，一宗定海之人。
- **外形**：青袍鹤发，身形清癯，立于大殿石阶如剑出鞘。
- **性格**：威严少言，赏罚分明；对人才有近乎苛刻的惜才之心。
- **定位**：秩序与规矩的化身。对萧炎：先冷眼（外门出身低微），后器重
  （c18 对质后亲授入门功法）。
- **出场片段**：c03 / c18。

### 楚天阔（senior_brother，内门大师兄）
- **身份**：内门首席，剑修，筑基中期，宗门年轻一辈第一人。
- **外形**：白衣负剑，眉目疏朗，笑起来像邻家兄长。
- **性格**：爽朗护短，行事光明；信奉「剑正则人正」。
- **定位**：主角在宗门内的引路人与靠山。c05 解围结缘，c17 秘境驰援
  是他「剑正」的注脚。
- **出场片段**：c05 / c09（观战） / c15 / c17。

### 赵擎（rival，外门师兄·反派）
- **身份**：赵家商盟嫡子，外门「第一」，仗家资笼络人心。
- **外形**：锦袍束金，面相倨傲，眼尾下垂带三分阴鸷。
- **性格**：傲慢记仇，输不起；家族利益高于一切。
- **定位**：宗门篇主要对手。c03 结怨 → c08 约战 → c09 败北 → c10
  私通魔道 → c16 背刺 → c18 叛宗出逃。他不是纯粹的恶人，是被
  「输不起」和家族裹挟推下去的人。
- **出场片段**：c03 / c04 / c08 / c09 / c10 / c15 / c16 / c18。

### 玄机老人（sweep_elder，藏经阁扫地老人）
- **身份**：宗门最底层杂役，扫了四十年藏经阁。真实身份本篇只揭一半。
- **外形**：佝偻瘦小，灰布短打，簸箕扫帚不离手，眼睛浑浊却偶尔
  亮得吓人。
- **性格**：疯言疯语与一针见血交替；只对扫地和「有缘人」上心。
- **定位**：身世线的钥匙。c07 一语点破功法关窍；c19 半揭玉佩来历
  （**药王谷**旧物、生父出走之谜），在第三阶段全揭。
- **出场片段**：c06 / c07 / c19。

### 玄鸦（dark_cultivator，魔道使者·蚀骨门）
- **身份**：魔道「蚀骨门」外围使者，专事收买、监视、灭口。
- **外形**：通身黑袍，斗笠压面，声音沙哑如鸦；袖间隐有骨哨。
- **性格**：阴冷高效，只谈交易不谈恩怨；对「萧」字血脉有任务级的
  敏感（c17 台词「那家人的余孽」——魔道与萧家旧怨的钩子）。
- **定位**：第三阶段大反派的前哨。c10 / c16 幕后，c17 正面现身，
  c18 携赵擎遁走。
- **出场片段**：c10（剪影） / c16（幕后指使） / c17 / c18（遁走）。
