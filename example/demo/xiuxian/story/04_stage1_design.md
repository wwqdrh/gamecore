## 1. 阶段定义与通关要求

**第一阶段 = 萧宅起步 → 青云坊入门 → 突破斗者。**

舞台：`home`（萧宅农田）→ `xiaozhai`（萧宅）→ `xiaozhen`（青石镇）→
`town`（青云坊）四张固定图 + 秘境随机副本（练手位）。
青草岭（map_a）/幽竹林（map_b）为第二阶段舞台，本阶段**只可远观不可进入**
（传送点未激活，对话铺垫）。

### 通关要求（硬性验收，全满足即通关）

| # | 条件 | 验收方式 |
|---|---|---|
| T1 | 主线链完成（报到→安顿→灵田风波） | 任务面板状态 + flag `story_p1_done` |
| T2 | 等阶突破**斗者**（斗之气 10 级 + `break_qizhe`×3） | 等阶表 breakthrough 判定 |
| T3 | 见证收束对话（长老吐露父亲线索、赠 `token_sect`） | flag `token_sect_granted` |

### 软性完成度（非通关必需，给养成玩家目标）

- 灵石 ≥ 100（经济参与度）
- 持有 `sword_qingfeng`（side_002 铸剑路径）
- 秘境副本首通（妖王首杀解锁 `map_secret`，第二阶段钩子）
- 农田一次完整收获（锄→浇→种→收教学闭环）

**通关演出**：突破成功 → 长老收束对话 → 青草岭传送点亮起（金光）+
「第二阶段开启」字幅。剧情推进 = 能力解锁，与幕一「突破收束」同构。

## 2. 游戏目标（玩家视角三层）

| 层 | 目标 | 支撑系统 |
|---|---|---|
| 主线 | 入门青云宗、查明「罪臣之子」疑云的第一条线索 | 任务链 + 对话 flag |
| 养成 | 斗之气→斗者：刷修为（副本/任务）、攒突破材料、换装备 | 等阶表 + 副本 + 农田/采集 + 商店 |
| 叙事 | 父亲云澈十年前失踪的真相碎片（旧档失窃/令牌伏笔） | 对话 + 拾取触发位 |

循环模型：**接任务 → 出门（副本/农田/采集）→ 回坊市（卖/买/交任务）→
修为与材料 → 突破**。每圈 8~15 分钟，阶段全程目标 60~90 分钟。

## 5. 敌人设计（第一阶段战斗位）

现有敌人资源：`slime`（草妖）/ `fox`（灵狐）/ `golem`（石傀），
组件链 Health / Hurtbox(layer3+defense) / Hitbox(mask2+attack) / Brain 齐备。

| 敌人 | 出现位 | 定位 | 数值（落档，M2） |
|---|---|---|---|
| 地灵鼠 | home 灵田（main_002 事件，3 只） | 战斗首课：必胜但会掉血 | 攻 3 / 血 20 / 经 40 |
| 草妖 slime | 秘境一层、宗门巡逻任务位 | 基础经验怪 | 攻 5 / 血 30 / 经 60 |
| 二层缩放怪 | 秘境二层（血×1.6 攻×1.5 经×2） | 「灵妖」位：傀儡血~192 | 基础值 × 楼层系数 |
| 妖王（石傀放大 1.5） | 秘境三层 boss | 阶段挑战天花板，首杀掉 `map_secret` | 攻 14 / 血 320 / 防 6 / 经 500 |
| 石傀 golem | （第二/三阶段）本阶段不出战 | — | — |

- fox 复用为秘境妖王（现有 dungeon boss 位），golem 留给第二阶段幽竹林缘
  精英战与第三阶段守府战——与三幕剧本 beat 6/9/10 对齐。
- 地灵鼠 = slime 换皮（体型缩小/棕色 tint），专用 home 农田事件，
  死亡不掉落，按任务计数（kill target_role=地灵鼠）。
- 经验闭环校算：斗之气 1→10 级共需 100+200+…+1000 = **5500 修为**。
  来源配比目标：任务 ~1800 + 副本一轮（3 层 ~1200）×2~3 次 + 日常签到
  （80/日）+ 丹药 `pill_exp_s/m` 补足。玩家约 8~12 圈循环可满级。

## 6. 资源与经济矩阵

### 产出 → 消耗

| 资源 | 产出源 | 消耗去向 |
|---|---|---|
| 修为 exp | 击杀/任务奖励/pill_exp_s(100)/pill_exp_m(300) | 等阶升级 |
| 灵石 | 任务奖励、副本结算 | 商店购丹药/种子 |
| 金币 coins | 支线（side_003 得 50） | 预留（镇级消费） |
| break_qizhe ×3 | beat 7 长老赠 1 + 商店售 2（120 灵石/颗） | 突破斗者 |
| pill_hp/mp | 商店、任务奖励、副本战利品池 | 战斗回复 |
| 种子/作物 | 商店购种 → 农田种植 | 出售换灵石 / 支线交货 |
| herb_lingzhi/xueshen | 采集点（xiaozhen 周边、秘境） | side_001 交货 / 售卖 |
| ore_coldiron | 采矿点（可开采 deco） | side_002 铸剑 |
| 装备 | sword_qingfeng（side_002）、robe_yunwen（商店） | 攻/防成长 |

经济锚点：突破材料商店价使「灵石 ≥100」软目标与突破需求吻合；
商店不售 `map_secret`/`token_sect`（剧情道具无价）。

## 8. 缺口汇总（需新增实现项）

1. **开场引导**（beat 0）：出生点=home 农田；分步教学提示条
   （移动→锄→浇→种→收→开地图），现有 UI 无引导组件 → 轻量实现
   （Label 队列 + 完成条件回调）。
2. **地灵鼠**：slime 换皮变体 + home 农田事件刷怪/清剿回调。
3. **main_003 任务**：task.json 新条目 + 突破推进回调接任务系统。
4. **主线对话段**：elder beat4/6/7 三段、小翠/萧夫人/说书先生各一段、
   外门弟子 beat5/6 续写、孙半城失窃一句（纯 timeline 文本）。
5. **传送门控**：map_a/map_b 传送点本阶段未激活（占位锁 +
   对话提示「修为不足」），突破斗者后 map_a 点亮。
6. **突破演出**：突破成功时的简单演出（光效 + 字幅），复用现有 UI 层。
7. **失窃事件触发位**：beat 6 用「入夜 + 与说书先生对话」组合触发，
   flag 门控，不新增系统。
