## 一句话梗概

一个卡在入门瓶颈的青云宗外门弟子，为寻找十年前失踪于落霞秘境的父亲，
在层层突破中揭开幕后黑手重启封印的阴谋，最终接过守护宗门的担子。

## 基调

热血修仙 + 少年成长。对白干净利落，少用感叹号；长辈话短意深，
反派从容阴冷，不咆哮。

## 核心冲突

百年前青云宗联手封印落霞秘境深处的帝血古修遗府。魔道「幽冥殿」殿主墨渊
潜伏宗门多年，要重启封印夺取遗府中的龙血精重塑肉身，需以秘境生灵血祭。
主角之父云澈十年前察觉端倪，携秘境残图追查，自封于秘境深处生死未卜——
**这个冲突只能由主角解决**：残图只认云家血脉，封印钥匙在他身上。

## 文案规范摘要

- **命名**：丹药 = 主材意象 + 剂型（聚气散/凝罡丹/天心莲液）；功法 = 意象+式；
  地名 = 景观+岭/林/涧/府。
- **称谓**：弟子称长老「长老」自称「弟子」；平辈互称师兄师姐/道友；
  魔道称凡人「蝼蚁」，自称「本座」。
- **禁用**：现代词汇；长句（对话框两行内）；连续三句以上同人物独白。
