# 01 世界观与人物

## 世界观设定

### 时代与舞台

斗气大陆东境，修真宗门林立。**青云宗**立于云岭山脉南麓，山门内分外门、
内门两级，执事堂总揽弟子事务；山门外**坊市**是散修与宗门交易的集镇。
北面**幽竹林**阴气终年不散，是宗门划定的禁地。

| 地图 | 景观 | 剧情定位 |
|---|---|---|
| town（青云山门） | 山道、执事堂、坊市东街 | 第一幕主舞台：日常、引子、突破 |
| map_a（青草岭） | 草甸丘陵，妖兽出没 | 第二幕前半：练手、采集、残图线索 |
| map_b（落霞秘境） | 霞光废墟、古修遗府 | 第二幕后半～第三幕：真相、决战 |

（town/map_a/map_b 对应 `map/` 下现有场景资源。）

### 规则体系

修行等阶十一阶，与 `state/level` 等阶表完全一致：

> 斗之气 → 斗者 → 斗师 → 大斗师 → 斗灵 → 斗王 → 斗皇 → 斗宗 → 斗尊 → 斗圣 → 斗帝

每阶十级，级满只凭修为可晋；阶与阶之间需服食对应突破丹药冲关
（聚气散、凝罡丹、破障丹……帝品雏丹，见 item 表 `break_*` 条目）。
修为可由斩妖、丹药（聚灵散/凝碧丹）获得。

### 核心冲突

见总纲。补充世界观事实（碎片化叙事素材）：

- 帝血古修是上古斗帝陨落所化，遗府中蕴**龙血精**（道具 `mat_longxue`），
  可再造肉身根基——斗圣问鼎斗帝的最后阶梯（正是 `break_doudi` 材料）。
- 百年前封印由青云宗首座与当时执事长老联手布下，钥匙一分为二：
  秘境残图（`map_secret`）与云家血脉。
- 幽冥殿百年前封印一役元气大伤，殿主墨渊蛰伏至今。

### 基调

热血 + 成长。第一幕轻快带一点窘迫（新人受气），第二幕渐沉（真相与代价），
第三幕爆发后归于余味。

## 人物设计

### 主角：云舟（玩家）

| 字段 | 内容 |
|---|---|
| 姓名/称谓 | 云舟；外门弟子称其「云师弟/师妹」（性别中立写法） |
| 身份 | 青云宗外门弟子；失踪执事云澈之子（第一幕末揭露） |
| 性格 | 倔、口硬心软；受激必反，受恩必记 |
| 动机 | 外部：寻父。内在缺口：父亲失踪后被宗门同侪视为「罪臣之子」，渴望被认可 |

| 成长弧线 | 「证明给别人看」→「明白守护是自己的选择」，中点反转后动机从寻父转向担责 |
| 玩法绑定 | 玩家角色；GdRoleSpeaker 名「云舟」，无立绘 |

### 核心配角

**玄诚长老（执事长老）** — NPC 已有：站桩于执事堂，role_name「执事长老」。
百年前封印一役唯一的在世亲历者，现任执事长老。性格：寡言，护短。
动机：守着封印与云家两代人的秘密，等一个能接担子的人。
玩法绑定：主线发布人（elder_timeline 已有山门指引对话，主线任务在此续写）。

**孙半城（坊市商人）** — NPC 已有：AI_WANDER 游走吆喝，role_name「坊市商人」。
坊市万宝斋掌柜，市侩却重信。动机：灵石，以及「整条街最灵通的消息贩子」的
自尊。玩法绑定：商店/经济入口 + 支线 side_herb 发布人。

**苏小棠（外门弟子）** — NPC 已有：AI_PATROL 巡逻东街，role_name「外门弟子」。
同批入门的挚友，嘴上不饶人。动机：想证明外门弟子不比内门差（与主角
镜像的内在缺口）。玩法绑定：挚友支线 side_spar 发布人；第二幕末被掳
推动最低点。

### 反派

**墨渊** — 幽冥殿主，潜伏青云宗多年（第一幕以「客卿供奉」身份露脸不露名）。
性格：从容、礼貌、视众生为棋子。动机：自圆其说——「宗门所谓封印，
不过是把上古传承锁进私囊；我要的只是取回应有之物」。外形：玄袍玉冠，
常年白手套（藏尸气）。弧线：无（功能性反派），但每幕露影子一次：
一幕坊市失窃、二幕夺图掳人、三幕血祭开府。
玩法绑定：不出场战斗（demo 规模），以对话 + golem 石傀作为其意志化身。
