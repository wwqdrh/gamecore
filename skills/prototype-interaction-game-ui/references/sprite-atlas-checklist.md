# 游戏 UI 精灵图（Sprite Atlas）控件清单

> 说明：精灵图集按**功能模块打包**，共 16 张图集（12 张 UI 控件图集 + 4 张游戏内容图标图集），避免图集过大。
> 适合 Godot、Unity、Cocos、虚幻 2D UI，俯视角 / 2D RPG、模拟经营、回合制游戏通用。
> 生成每张图集时，将对应模块的控件逐项填入 SKILL.md 的「单张图集提示词模板」。
> **按页面追加生成（按需图集）**：用户只要页面原型图时，从本清单中挑出该页面实际用到的控件，打包成 1-2 张本页精灵图（≤20 个控件出 1 张，超出拆 2 张），风格继承该页面原型；无需覆盖全部模块。
> **全局硬性要求：所有图集严禁出现任何文字（汉字、字母、数字、符号）。按钮文案、标签文字、数量数字一律不画，由引擎后期叠加。**
